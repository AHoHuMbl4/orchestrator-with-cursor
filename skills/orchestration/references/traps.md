# Ловушки оркестрации — читать перед пачкой

Формат: ловушка → признак → обход. Встретил новую — добавь строку в таблицу.

| # | Ловушка | Признак | Обход |
|---|---|---|---|
| 1 | Промт-текст литералом в командной строке | гейты/шелл ловят слова из промта; кавычки ломают запуск | промт из файла: `-p "$(cat файл)"` или argv без shell |
| 2 | Свобода в промте («или другой способ») | исполнители делают разное, сводки расходятся | путь/инструмент/команда дословно |
| 3 | Вера сводке исполнителя | факты в отчёте врут при верном результате | приёмка только замером (файл/тест/счётчик лога) |
| 4 | Один прогон — много задач | поздние задачи делаются хуже | 1 задача = 1 агент; пачка — параллельно |
| 5 | Критик видит лог исполнителя | критик наследует его заблуждения | критик получает только дифф + критерий |
| 6 | Параллельные пишущие исполнители на одной области | конфликты, несогласованные решения | пишет один; параллельные — read-only |
| 7 | `pkill/pgrep -f` с подстрокой промта | агент убивает сам себя (промт в argv) | уборка процессов по PID, без масок по тексту |
| 8 | Многострочный код через `-c` в обёртках | ложные выводы от экранирования | диагностика heredoc-файлом |
| 9 | Тихий exit 0 у headless-запусков (`claude -p`) | «готово», а действия не было: отказы прав не меняют exit code | проверять поле `permission_denials` в json/result; `--permission-prompts none` (старые сборки — `--permission-mode dontAsk`) |
| 10 | Модели/флаги из памяти | неверный флаг или модель — прогон впустую | снимать списки с движка перед боем |
| 11 | Повышение таймаута вместо декомпозиции | частые 124 (timeout_s) | дробить задачу; прогресс — подшагами |
| 12 | Дрейф цели в длинной сессии | агент «упоролся» и делает не то | сверка с `.orchestration/compass.md` каждые reground.every_min минут (§ Сверка курса в ../SKILL.md) |
