# Ловушки оркестрации — читать перед пачкой

Формат: ловушка → признак → обход. Встретил новую — добавь строку в таблицу.

| # | Ловушка | Признак | Обход |
|---|---|---|---|
| 1 | Промт-текст литералом в argv/URL облачного запуска | гейты/шелл/логи ловят слова из промта; кавычки ломают команду | промт только из файла: `run-cloud.py … --prompt-file P.md` (тело API — `prompt={"text":…}`) |
| 2 | Свобода в промте («или другой способ») | исполнители делают разное, сводки расходятся | путь/инструмент/команда дословно |
| 3 | Вера сводке исполнителя | факты в отчёте врут при верном результате | приёмка только замером (файл/тест/счётчик лога / `run-cloud.py artifacts`) |
| 4 | Один прогон — много задач | поздние задачи делаются хуже | 1 задача = 1 агент; пачка — параллельно |
| 5 | Критик видит лог исполнителя | критик наследует его заблуждения | критик получает только дифф + критерий |
| 6 | Параллельные пишущие исполнители на одной области | конфликты, несогласованные решения | пишет один; параллельные — read-only |
| 7 | `pkill/pgrep -f` с подстрокой промта | агент убивает сам себя (промт в argv) | уборка процессов по PID, без масок по тексту |
| 8 | Многострочный код через `-c` в обёртках | ложные выводы от экранирования | диагностика heredoc-файлом |
| 9 | Тихий exit 0 у headless-запусков (`claude -p`) | «готово», а действия не было: отказы прав не меняют exit code | проверять поле `permission_denials` в json/result; `--permission-prompts none` (старые сборки — `--permission-mode dontAsk`) |
| 10 | Модели/флаги из памяти | неверный флаг или модель — прогон впустую | снимать списки с движка перед боем |
| 11 | Повышение таймаута вместо декомпозиции | частые таймауты / долгий polling cloud | дробить задачу; прогресс — подшагами |
| 12 | Запись задачи в общий compass / дрейф цели | агент или CLI пишет в `.orchestration/compass.md` вместо сессионного | задача пишется ТОЛЬКО в сессионный compass; общий шаблон редактируется только владельцем в панели (Расширенные); CLI/global-пути записи запрещены; сессионный compass создаётся автоматически из шаблона при первом сообщении сессии |
| 13 | Отчёт без строки-вердикта или без доказательств | «я сделал» текстом; нет `Вердикт: OK|PROBLEMS|BLOCKED` и блока команд/артефактов | непринят; приёмка только по вердикт-конвенции + замер оркестратора |
| 14 | Оркестратор сам сшил финальный ответ в своём контексте | доклад без волны синтезаторов/критиков по артефактам | синтез — отдельная волна через критиков; оркестратор только выбирает лучший |
| 15 | Декомпозиция без стоп-вопросов при неоднозначном запросе | пачка стартовала без предмета/критерия готовности | СТОП, 1–3 вопроса или Assumptions; иначе мусор на выходе |
| 16 | Устаревший локальный CLI Cursor как «режим» | старые сессии, params или промты ищут PATH-бинарник / удалённый лаунчер | режима нет: исполнители — только `cursor-cloud` (`run-cloud.py` + ключ) или субагенты движка (явное «да»); `auto` = ключ→cloud, нет ключа→стоп-вопрос; упоминания локального агента в старых сессиях — игнорировать |
