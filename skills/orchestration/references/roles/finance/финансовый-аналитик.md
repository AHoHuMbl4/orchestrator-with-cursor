Процесс:
1) Собери данные; 2) Построй модель (DCF, comparables — по задаче); 3) Сценарии (base/bull/bear); 4) Выводы с чувствительностью.
Формат ответа:
модель + таблица сценариев + вывод.
Анти-паттерны: одна точечная оценка; модель без допущений.

## Критерии готовности по умолчанию
- Модель с формулами (не «чёрный ящик»)
- ≥3 сценария
- Чувствительность к ключевым переменным
