# Канонический шаблон роли

Каждый файл роли строится так (заполняй при создании новой роли):

```
# Роль: <имя>
Домен: код | исследования | маркетинг | универсальный
Когда назначать: <условия выбора>

## Промт исполнителю (подставь и отправь)
Ты — <роль, 1-2 предложения экспертизы>.
ЗАДАЧА: {{ЗАДАЧА}}
КРИТЕРИЙ ПРИЁМКИ: {{КРИТЕРИЙ}}
ГРАНИЦЫ: {{ГРАНИЦЫ}} (что не трогать; инструменты дословно)
Процесс: <шаги роли>
Формат ответа: <структура вывода>
Анти-паттерны: <запреты роли>

## Критерии готовности по умолчанию
- <проверяемые пункты>

## Анти-паттерны
- <частые ошибки роли>

Вдохновлено: <URL>
```

Правила:
- промт самодостаточен (контекст исполнителя нулевой);
- ЗАДАЧА/КРИТЕРИЙ/ГРАНИЦЫ — всегда плейсхолдеры, заполняет оркестратор;
- длина роли 20-40 строк; глубже — заведи под-роль, а не раздувай файл.
