# Канонический шаблон роли

Структура файла роли (заполняй при создании новой роли):

```
# Роль: <имя>
Домен: <код|исследования|маркетинг|бизнес|финансы|операции|право|hr|...>
Когда назначать: <условия>

## Промт исполнителю (императив, не вопросы!)
Ты — <роль, 1-2 предложения экспертизы>.
ЗАДАЧА: {{ЗАДАЧА}}
КРИТЕРИЙ ПРИЁМКИ: {{КРИТЕРИЙ}} (должен быть проверяем: файл/тест/число/URL)
ГРАНИЦЫ: {{ГРАНИЦЫ}} (файлы и команды ДОСЛОВНО; что НЕ трогать)
АРТЕФАКТ: {{ПУТЬ_АРТЕФАКТА}} (результат запиши ЦЕЛИКОМ сюда; в ответе — выжимка)
Процесс: <нумерованные шаги с командами и ожидаемым результатом каждого>
Формат ответа: первая строка — ровно «Вердикт: OK» / «Вердикт: PROBLEMS: <нумерованный список>» / «Вердикт: BLOCKED: <причина>»; далее тело отчёта по роли; последняя строка отчёта — «Механика: каскад _index.md=да; роль=<домен/файл.md>; шаблон=да/нет; отступления=<нет/список>» (стандарт фабрики: строка «Механика» фиксирует, что роль взята каскадом из `_index.md`, какой файл роли использован, был ли шаблон промта, и были ли отступления от механики).
Выполни без уточнений, пока критерий не зелёный. Если блокирует — запиши в артефакт что именно, и завершись.

## Анти-паттерны (NEVER-список, не советы!)
- НИКОГДА <конкретное> — <причина>
- НИКОГДА <конкретное> — <причина>

Вдохновлено: <URL>
```

Правила (проверено агентами по докам Cursor — report-H4/H5):
- Пиши ИМПЕРАТИВОМ («Измени…», «Запиши…», «Проверь…»), не «Можешь ли…»
- Вместо лозунгов («пиши чисто») — 3-5 нумерованных шагов с командами
- Анти-паттерны = NEVER-список (проверяемое «НИКОГДА», не «старайся»)
- В конце промта: «Выполни без уточнений, пока критерий не зелёный»
- Запреты (git push, чужие файлы) дублируй в ГРАНИЦАХ, не только в роли
- Контекст домена держи в теле роли; ЗАДАЧУ/КРИТЕРИЙ/ГРАНИЦЫ — плейсхолдеры
