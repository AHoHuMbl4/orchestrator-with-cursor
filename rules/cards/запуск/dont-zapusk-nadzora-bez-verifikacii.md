## суть
Команда запуска прокурора/наблюдателя упала («не найден») — запуск не проверили; поздние круги волны шли без надзора молча. Живой кейс владельца 03.10: надзор «считается включённым», пока его нет.

## как чинить
Запуск надзора = ДВА шага: команда + немедленная проверка факта (journal start жив / pid / heartbeat). Механизм: упавший/умерший надзорный ран даёт видимый сигнал ≤60 с (supervision_dead); приёмка волны требует записи надзора за её окном. Связь: MM-C2 (прокурор волны).
